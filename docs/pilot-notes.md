# Pilot decisions

Last updated: 2026-10-31

The original 720-row pilot is retained in reports/pilot-initial. It revealed that
structured checks detect numeric failures missed by text matching, and that
strict evidence sufficiency rejects a large fraction of the invented questions.
Four source families do not support empirical reliability or superiority claims.

A measurement audit found that baseline timing included offline verification
used solely for scoring. The corrected runner times direct answering, retrieval
and citation lookup separately from offline scoring diagnostics. The original
pilot remains available, is not final evidence, and is superseded by reports/pilot.
No final test outcomes had been generated when this correction was made.

The final design retains the proposed five percentage point practical support
effect and two percentage point maximum coverage loss as descriptive thresholds.
It uses a bounded allocation of 24 test families plus 12 shifted families, rather
than claiming that repeated invented templates constitute powered empirical data.
The corrected pilot's planning.json records paired variance and conditional
sample-size arithmetic. Calibration uses the separate twelve calibration families.

Direct, retrieval and citations use the same scripted answers; this isolates
filtering rather than measuring how a real reader's generations improve with
retrieval. Oracle evidence is the same exhaustive supplied corpus, an identity
diagnostic. Missing, unauthorized and future evidence cannot be manufactured by
an oracle. Actual retrieval-search errors and real model factuality remain untested.

Independent pilot annotations have not been supplied. Consequently, the final
synthetic run can support a provisional reproducibility report, while AI-02's
annotation requirement and full research completion remain open.
