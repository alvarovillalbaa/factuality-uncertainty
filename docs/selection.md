# AI-02 selection and scope

Last updated: 2026-10-31

EN-03, AI-01 and FND-02 already exist as merged local releases. AI-02 is the
next decision-experiment project in the ZIP execution sequence. Its only required
package dependency is FND-01; AI-03 and AI-05 remain optional artifact producers.
No other specification is implemented in this repository.

The initial domain is invented technical specifications, units and arithmetic.
All three requested tracks (short questions, long answers, numeric statements)
use synthetic content with known labels. Real engineering documents, hosted
answerers, TruthfulQA and FActScore data require separate rights, version and
reviewer decisions. No such datasets are downloaded or redistributed.

Independent human pilot/final annotation is explicitly required by the spec.
It has not been commissioned. Exact executable references can check synthetic
answers but cannot be represented as human annotation or qualified domain audit.
The release audit must retain this distinction and any resulting open gate.

Storage Guard: 27.6 GiB free, 30.1 GiB required for reserve plus 0.1 GiB estimate.
No installation, large worktree, build or database is authorized on that result.
Source files and bounded local checks use an existing interpreter and dependencies
read-only. No prior task's storage exception applies.
